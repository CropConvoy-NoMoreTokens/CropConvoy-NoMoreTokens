# P2: market and platform

Start with docs/handoffs/P2-MARKET-PLATFORM.md. repository.ts uses parameterized PostgreSQL when DATABASE_URL is configured, with temporary memory available only in stub mode without a database. The MarketRepository interface remains unchanged for workflow. service.ts exports extractHarvest and findMarket with the agreed contracts. Gemini extraction uses constrained JSON output and asks for missing fields. Matching accepts only existing eligible order IDs and falls back to deterministic sorting with labeled reasons when Gemini fails. Publication still requires the separate confirmed listing request.

Set LLM_API_KEY and LLM_MODEL in api/.env, run npm run llm:check to verify model access and tool calling, then set API_STUBS=false for model calls. With DATABASE_URL set, npm run market:check verifies a real tool call and filtered candidate against temporary synthetic rows, then removes those rows. Until P3/P4 finish their modules, trip creation and plan generation are still unfinished. Never copy LLM_API_KEY into web/ or a VITE_ variable.
